## Compatibility

The dsh-arena source kind belongs to the single user message that starts one Arena contender, and no consumer dispatches on the kind outside the producing package, so readers preserve its content unchanged. Older readers see an unknown source kind and keep the message as ordinary user input, which reconstructs the same model history; newer readers reading older logs see no arena message and every prior kind keeps its meaning, so no discriminator is reinterpreted.
